# YouthMind API Test Suite

Complete test suite for YouthMind API endpoints.

## Quick Start

```bash
# 1. Start backend
cd ../../backend && ./start-backend.sh

# 2. Run tests
cd ../scripts/api-testing && bash test_all_endpoints.sh
```

- 622 tests across 25 batch files
- Covers 416+ API endpoints
