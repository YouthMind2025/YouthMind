# YouthMind

**YouthMind** is an AI-powered mobile app focused on improving youth mental health by combining personalized emotional support, community interaction, and gamified engagement.

## 🌟 Features
- Emotion recognition and tracking
- Journaling and progress visualization
- Supportive community discussion boards
- Daily mental wellness challenges
- AI-based content and recommendation engine

## 🧠 Tech Stack
- **Frontend**: Flutter (Clean Architecture + BLoC)
- **Backend**: Django (Microservices), FastAPI for AI services
- **AI**: Emotion classification, recommendation systems
- **Cloud**: AWS (ECS, S3, RDS, Redis, SageMaker)
