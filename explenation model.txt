1、用户发帖部分算法：
当用户发帖时，微调模型会对文本进行心理分析，输出一个 43 维的原始心
所向量 V_raw，代表这条帖子的心理成分。同时系统会输出一个强度因子 θ
∈ [0, 1]，表示该帖对用户心理影响的显著程度（即“心理冲击量”）。
随后系统更新当前用户的种子向量 S，方式如下：
S_new = α · V_raw + (1 - α) · S_prev
其中 α = base_alpha + θ（受发帖强度影响）
θ：θ 是一个权重因子，表示“单条内容（如帖子、文档）对用户向量/
语义空间的影响程度”。它取值在 [0,1]，数值越大，说明该内容越“重要”
或“有冲击力”，对用户表示的更新贡献就越大。
2、用户互动部分算法：
当用户与他人的帖子产生互动（如共鸣、停留）时，平台直接使用被互动
帖中已有的原始心所向量 R_raw，表示“他人的心理表达”。
这时要将用户当前的心理状态 S_prev 和系统提供的正价平衡向量 B（例
如抑制“瞋”“痴”，增强“喜”“舍”）共同作用于 R_raw，进行调制：
R′ = R_raw × (1 + β · S_prev + μ · B)
其中：
β 是用户当前心理状态对外界共鸣影响的放大系数
μ 是系统设置的正价心所放大因子
B 是一个固定的 43 维向量，增强正面心所、削弱负面心所
为了防止某些心所维度数值爆炸，进行 clip 限制：
R′′ = clip(R′, lower_bound, upper_bound)
之后，融合进用户状态：
S_new = Ws · R′′ + (1 - Ws) · S_prev
其中：
Ws 是本次互动的行为权重（如共鸣 = 0.2，停留 = 0.01）
S_prev 是当前用户心理状态
3、更新机制：
每一个用户在触发用户发帖或用户互动部分的算法后，会实时执行算法，
实时更新 S 向量。
发帖项：
S_new = α · V_raw + (1 - α) · S_prev
α = base_alpha + θ
互动项：
R′ = R_raw × (1 + β·S_prev + μ·B)
R′′ = clip(R′)
S_new = Ws · R′′ + (1 - Ws) · S_prev
更新过程中，当前用户的 S 将用于推荐算法
4、人格计算算法
每周或每月将所有用户发帖中的 V_raw 集合（历史表达），用 θ 作为权
重加权平均：
μ_post = weighted_mean(V_raw_post_i, weight = θ_i)
这个 μ_post 表示用户主动心理偏好，是“显性人格”。
每周或每月从所有互动帖 R_raw 中，统计每一维出现较大值的频率，提取
出 Top-K 高频共鸣心所维度 Ψ，然后构造一个只保留这些维度的“潜意识共
鸣向量”Vshadow
最终人格向量融合公式：
μ = λ1 · μ_post + λ2 · V_shadow
（如 λ1 = 0.7, λ2 = 0.3）
μ 为用户人格中心向量（可映射至五大人格或平台的自定义维度）

1. User Posting Algorithm
When a user posts, the fine-tuned model performs psychological
analysis on the text and outputs a 43-dimensional raw mental factor
vector V_raw, representing the psychological components of the post.
At the same time, the system outputs an intensity factor θ ∈ [0,
1], which indicates how significant the psychological impact of the
post is (i.e., its “psychological shock value”).
The system then updates the user’s current seed vector S as follows:
𝑆𝑛𝑒𝑤 = 𝛼 ⋅ 𝑉𝑟𝑎𝑤 + (1 − 𝛼) ⋅ 𝑆𝑝𝑟𝑒𝑣
where
𝛼 = 𝑏𝑎𝑠𝑒_𝑎𝑙𝑝ℎ𝑎 + 𝜃(influenced by posting intensity).
 θ: a weighting factor representing how much influence a single
piece of content (e.g., a post or document) has on the user
vector/semantic space.
o Range: [0, 1]
o The larger the value, the more “important” or
“impactful” the content, and the greater its
contribution to updating the user’s representation.
2. User Interaction Algorithm
When a user interacts with another person’s post (e.g., resonance,
dwell), the platform directly uses the raw mental factor vector
R_raw from that post, representing the “other person’s
psychological expression.”
The system then modulates R_raw by combining it with the user’s
current mental state S_prev and the system-provided positive balance
vector B (e.g., suppressing “anger” and “delusion,” enhancing
“joy” and “equanimity”):
𝑅' = 𝑅𝑟𝑎𝑤 × (1 + 𝛽 ⋅ 𝑆𝑝𝑟𝑒𝑣 + 𝜇 ⋅ 𝐵)
where:
 β: amplification factor of how the user’s current state
influences external resonance.
 μ: amplification factor for positive mental elements set by
the system.
 B: a fixed 43-dimensional vector that enhances positive factors
and reduces negative ones.
To prevent certain dimensions from exploding in value, a clip
constraint is applied:
𝑅'' = 𝑐𝑙𝑖𝑝(𝑅',𝑙𝑜𝑤𝑒𝑟_𝑏𝑜𝑢𝑛𝑑, 𝑢𝑝𝑝𝑒𝑟_𝑏𝑜𝑢𝑛𝑑)
Then, it is integrated into the user’s state:
𝑆𝑛𝑒𝑤 = 𝑊𝑠
⋅ 𝑅'' + (1 − 𝑊𝑠) ⋅ 𝑆𝑝𝑟𝑒𝑣
where:
 W_s: interaction weight (e.g., resonance = 0.2, dwell = 0.01).
 S_prev: user’s current mental state.
3. Update Mechanism
Whenever a user posts or interacts, the corresponding algorithm is
executed in real time, updating the S vector immediately.
 Posting:
𝑆𝑛𝑒𝑤 = 𝛼 ⋅ 𝑉𝑟𝑎𝑤 + (1 − 𝛼) ⋅ 𝑆𝑝𝑟𝑒𝑣, 𝛼 = 𝑏𝑎𝑠𝑒_𝑎𝑙𝑝ℎ𝑎 + 𝜃
 Interaction:
𝑅' = 𝑅𝑟𝑎𝑤 × (1 + 𝛽 ⋅ 𝑆𝑝𝑟𝑒𝑣 + 𝜇 ⋅ 𝐵)

During the update process, the user’s S vector is also used as input
for the recommendation algorithm.
4. Personality Computation Algorithm
 Weekly or monthly, collect all V_raw vectors from user posts
(historical expressions) and compute a weighted average using
θ as the weight:
𝜇𝑝𝑜𝑠𝑡 = 𝑤𝑒𝑖𝑔ℎ𝑡𝑒𝑑_𝑚𝑒𝑎𝑛(𝑉𝑟𝑎𝑤_𝑝𝑜𝑠𝑡_𝑖

 Similarly, from all interactive posts (R_raw), count the

 Finally, integrate explicit and implicit personalities:

(e.g., 𝜆1 = 0.7, 𝜆2 = 0.3)
