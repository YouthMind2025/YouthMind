## Runtime Test Script

```bash
#!/bin/bash

echo "YouthMind Recommendation Engine - Runtime Check"
echo "=============================================="

# 1. Start infrastructure
echo "Starting Redis and PostgreSQL..."
docker-compose up -d redis postgres
sleep 5

# 2. Compile application
echo "Compiling application..."
cd backend
./mvnw clean compile
if [ $? -ne 0 ]; then
    echo "❌ Compilation failed"
    exit 1
fi
echo "✅ Compilation successful"

# 3. Run tests
echo "Running tests..."
./mvnw test -Dtest=RecommendationEngineIntegrationTest
if [ $? -ne 0 ]; then
    echo "⚠️  Tests failed (expected if infrastructure not fully set up)"
fi

# 4. Start application
echo "Starting application..."
./mvnw spring-boot:run &
APP_PID=$!

# 5. Wait for startup
echo "Waiting for application to start..."
for i in {1..30}; do
    if curl -s http://localhost:8080/actuator/health > /dev/null; then
        echo "✅ Application started"
        break
    fi
    sleep 3
done

# 6. Check health
echo "Checking health..."
HEALTH=$(curl -s http://localhost:8080/actuator/health)
if echo "$HEALTH" | grep -q '"status":"UP"'; then
    echo "✅ Health check passed"
else
    echo "❌ Health check failed: $HEALTH"
fi

# 7. Check Redis Streams
echo "Checking Redis Streams..."
if redis-cli XINFO STREAM recommendation:rvector-updates > /dev/null 2>&1; then
    echo "✅ Redis Streams configured"
else
    echo "⚠️  Redis Streams not yet created (will be created on first event)"
fi

# 8. Check metrics
echo "Checking metrics..."
METRICS=$(curl -s http://localhost:8080/actuator/prometheus)
if echo "$METRICS" | grep -q "recommendation"; then
    echo "✅ Metrics available"
else
    echo "⚠️  No recommendation metrics yet (normal on fresh start)"
fi

# 9. Test API endpoint
echo "Testing API endpoint..."
STATUS_CODE=$(curl -s -o /dev/null -w "%{http_code}" \
              "http://localhost:8080/v1/feed/status?userId=test-user")
if [ "$STATUS_CODE" = "200" ] || [ "$STATUS_CODE" = "401" ]; then
    echo "✅ API endpoint accessible (status: $STATUS_CODE)"
else
    echo "❌ API endpoint not accessible (status: $STATUS_CODE)"
fi

# 10. Cleanup
echo "Stopping application..."
kill $APP_PID

echo "=============================================="
echo "Runtime check complete!"
```

## Troubleshooting Guide

### Issue: Application won't start
Solution:
- Check Java version: `java -version` (must be 17+)
- Check dependencies: `./mvnw dependency:tree`
- Check ports: `netstat -an | findstr :8080`
- Check logs: `backend/logs/spring.log`

### Issue: Redis connection failed
Solution:
- Start Redis: `docker-compose up -d redis`
- Check Redis: `redis-cli ping` (should return PONG)
- Check connection: `redis-cli -h localhost -p 6379`

### Issue: Database connection failed
Solution:
- Start PostgreSQL: `docker-compose up -d postgres`
- Check PostgreSQL: `docker-compose ps postgres`
- Check logs: `docker-compose logs postgres`

### Issue: Tests failing
Solution:
- Check TestContainers is working
- Check Docker is running
- Increase Docker memory allocation
- Skip tests temporarily: `./mvnw compile -DskipTests`

### Issue: API returns 500 errors
Solution:
- Check application logs
- Check Redis is available
- Check database is available
- Verify configuration in application.yaml
