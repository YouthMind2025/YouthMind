## 📊 **API DOCUMENTATION**

### AI Chat Endpoints

#### Send Message with AI Response
```http
POST /v1/conversations/{conversationId}/ai-chat
Content-Type: application/json
Authorization: Bearer <jwt-token>

{
  "text": "I'm feeling really anxious about school",
  "sender": "user"
}
```

**Response:**
```json
{
  "success": true,
  "data": {
    "messageId": "uuid",
    "response": "I understand that school can feel overwhelming sometimes. Let's talk about what's making you feel anxious...",
    "personalityUsed": "supportive",
    "emotionDetected": "anxious",
    "suggestedTopics": ["anxiety", "school"],
    "safetyFiltered": false,
    "confidence": 0.85,
    "followUpQuestions": ["What specific aspects of school are worrying you?"]
  }
}
```

#### Get Personality Profile
```http
GET /v1/ai-chat/personality-profile
Authorization: Bearer <jwt-token>
```

#### Update Personality Profile
```http
PUT /v1/ai-chat/personality-profile
Content-Type: application/json
Authorization: Bearer <jwt-token>

{
  "preferredPersonalityType": "empathetic",
  "communicationStyle": "gentle",
  "enableHumor": true,
  "enableEmpathy": true,
  "interests": ["mental health", "relationships"],
  "triggers": ["family issues"]
}
```
